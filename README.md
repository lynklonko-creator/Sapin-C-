# 🎯 GUESS THE NUMBER

Bienvenue dans **Guess the Number** ! 🎲

Un petit jeu où le joueur doit deviner un nombre choisi aléatoirement par le programme.

## 🎮 Comment jouer ?

1. Le programme choisit un nombre aléatoire.
2. Le joueur propose un nombre.
3. Le programme indique si le nombre proposé est **trop grand** ou **trop petit**.
4. Continue à essayer jusqu'à trouver le bon nombre ! 🏆
5. Vous n'avez que 5 essais !!!
